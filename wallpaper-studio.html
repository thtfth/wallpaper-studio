Local helper

A tiny local script gives this page permission to actually change your wallpaper — something no website can do on its own.

Checking for local helper…
  1. Keep all four files in one folder: this HTML file, wallpaper_server.py, start.bat and start.command.
  2. Windows: double-click start.bat.
  3. macOS and Linux: double-click start.command. If macOS opens it in TextEdit, it lost its executable bit on download — run chmod +x start.command in Terminal once.
  4. Either way the server starts, opens this page for you, and stops when you close its window.
  5. The helper needs Python 3. If it isn't installed, the launcher says so and offers to get it for you rather than failing silently.
  6. Come back here (or reload from that URL) — the dot above turns teal when it's connected.
You're running the packaged build, so there's nothing to install — the helper is inside the app you launched. Close its window to stop it.

Preferences

Everything — every section's text, font, size, color, position, saved titles, canvas settings — autosaves to the local helper a moment after you stop editing, and reloads automatically next time it's running.

Save states

Keep up to 5 snapshots you can come back to. Each one is named with the date you saved it; saving a sixth replaces the oldest.

Folders

Everything this app writes lives beside the scripts, in subfolders of the app's own folder. Your wallpaper is backed up on every start, and every generated image lands here. Each folder keeps its 10 newest files.
